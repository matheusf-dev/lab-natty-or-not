# Registro de prompts e decisões

## Contexto

Desafio DIO Lab Natty or Not: produzir conteúdo com IA generativa, documentá-lo no README, fazer fork do repositório e submeter seu link.

## Solicitações reais do usuário nesta conversa

1. “me ajude em um desafio da minha plataforma de estudos, pode ser?”
2. O usuário enviou o enunciado completo do desafio DIO, incluindo objetivos, template e endereço do repositório.
3. “**E-book de desenvolvimento Front-end**” — escolha da proposta de material educacional.
4. “faça” — autorização para executar a proposta de e-book, exemplos, projeto final e documentação.

## Especificações derivadas para produção

As descrições abaixo resumem decisões de produção adotadas a partir da proposta aprovada; não são transcrições de prompts independentes enviados a outras ferramentas.

- **Conteúdo:** criar um guia em português para iniciantes, com 12 capítulos sobre Web, HTML, CSS, JavaScript, Git e GitHub, incluindo introdução a React e TypeScript.
- **Didática:** explicar conceitos com exemplos pequenos, propor uma prática por lição e incluir respostas comentadas.
- **Design:** diagramar um PDF A4 com identidade tecnológica, tipografia legível, azul-marinho, ciano, tons neutros, blocos de código e diagramas vetoriais.
- **Projeto prático:** implementar um painel responsivo de estudos com HTML, CSS e JavaScript, progresso, reinicialização e armazenamento local.
- **Documentação:** preparar README no formato DIO e registrar limitações dos testes, com transparência sobre o uso da IA.

## Ferramentas e autoria

A geração de texto, código, design programático e documentação foi realizada com o ChatGPT. A capa e os diagramas foram desenhados em código com ReportLab, sem imagens externas nem um gerador de imagens separado. O PDF foi renderizado para inspeção visual e o projeto foi testado com Chromium/Playwright em condições controladas.

Antes da publicação, recomenda-se que o estudante execute o projeto localmente, revise o conteúdo, adapte o README à sua experiência e registre as mudanças que realizou pessoalmente.
